# 🐔 El Pollo Loco

A jump, run & throw game made purely in JavaScript. Help Pepe collect coins and bottles of tabasco salsa to fight the crazy hen across dynamically generated levels.

![El Pollo Loco](img/elpolloloco.png)

## ⌨️ Technologies

- `JavaScript` (object-oriented)
- `HTML`
- `CSS`

## 🚀 Features

- Object-oriented game architecture (characters, enemies, collectible items, status bars, etc.)
- Keyboard and mobile touch controls
- Animated character and enemies
- Collectible coins and tabasco bottles used to fight the end boss
- Dynamically generated levels
- Background music and sound effects

## 🚦 Running the Project

This is a static JavaScript project with no build step required.

1. Clone or download the repository.
2. Open `index.html` in your browser, or serve the folder with a local web server (recommended, e.g. the VS Code "Live Server" extension) to avoid browser restrictions on local file access.

## 📁 Project Structure

- `index.html` – main game entry point
- `js/` – game bootstrapping, keyboard handling, and mobile UI logic
- `models/` – object-oriented game classes (character, enemies, level, world, status bars, etc.)
- `img/` – sprites and image assets
- `audio/` – background music and sound effects
- `levels/` – level configuration
- `fonts/` – custom fonts
- `style.css` – global styles
